# SafeConnect AI

AI-inspired professional communication safety prototype.

## About

SafeConnect AI analyzes messages and identifies whether they appear to be:

- Learning / Educational
- Professional
- Contact Request
- Romantic / Personal
- Scam / Suspicious
- Other

## Features

- Message analysis
- Risk level detection
- Confidence score
- Message history
- Demo block action
- Responsive web interface

## Technology

- HTML
- CSS
- JavaScript
- LocalStorage

## Important Note

This is a prototype for communication-safety research and demonstration.

It does not automatically block users on LinkedIn and does not directly integrate with LinkedIn accounts.
